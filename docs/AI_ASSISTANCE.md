# AI Assistance

This project was developed using ChatGPT as an engineering assistant.

ChatGPT was used to assist with:

- brainstorming architecture
- reviewing design decisions
- generating boilerplate
- explaining framework behaviour
- debugging compile errors
- suggesting refactoring
- improving documentation

All architecture decisions, implementation choices,
testing and final code integration were reviewed and
validated before inclusion in the solution.

The project reflects an iterative software engineering
workflow rather than AI-generated code pasted without review.
